AboutImgy

A fast, local-first image and video organizer. Tag, search, favorite, group and rename your media from the browser. Nothing leaves this machine unless you turn on auto-tagging with a remote model.

  • Your folder is the source of truth: files copied into the library show up on the next refresh.
  • The database only holds tags, favorites, groups, your custom order and settings.
  • Press ? anywhere to see every keyboard shortcut.
Heads upImgy has no login. Anyone who can reach this server can view, change and delete your files. Keep it on localhost or a trusted network.

Appearance

Theme

Gruvbox dark or light. The sun and moon button in the top bar switches too.

The width of a gallery column. The slider next to Select changes it too.

Gallery order

Drag a file or a group in the gallery to move it, and the order switches to Custom. New files show up first until you place them.

Auto-taggingvision LLM

Imgy sends one image at a time to the model and applies the file name and tags it suggests. Videos are not supported.

Provider

Any OpenAI-compatible chat completions API with vision, such as Ollama.

Heads upImgy has no login. Anyone who can reach this server can read the key from settings.
Apply
Exclusive tag groups

The model picks at most one tag from each group. Once the library has tags, it only picks from those.

Tags

Every tag in your library and how many files carry it. Deleting a tag takes it off every file and out of the exclusive tag groups.
